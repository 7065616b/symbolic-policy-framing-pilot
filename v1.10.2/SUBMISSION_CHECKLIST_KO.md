# 제출 직전 확인 사항

최종 제출용 버전은 **v1.10.2**입니다. 반복 설명과 긴 문장을 줄이고, 원래 결과와 연구의 한계는 유지했습니다. 아직 학회에 접수한 상태는 아닙니다.

## 어떤 파일을 쓰면 되나

| 용도 | 파일 | 사용 방법 |
| --- | --- | --- |
| 논문 업로드 | [paper.pdf](paper.pdf) | 이 PDF 한 개를 제출합니다. 본문 8쪽, 참고문헌 1쪽, 요약 1쪽으로 총 10쪽입니다. |
| 제목·초록 입력 | [easychair_korean_abstract.md](easychair_korean_abstract.md) | Title의 영문 제목과 아래 국문 초록을 접수창의 각 칸에 복사합니다. 파일 제목·안내 문구는 복사하지 않습니다. |
| 수정·보관 | main.tex, kaia.cls, images/ | 편집 소스입니다. 접수창에서 요구하지 않으면 별도로 올릴 필요가 없습니다. |

## 접수 화면에서 마지막으로 볼 것

1. **마감 시각과 접수 가능 상태:** 접수 화면에서 확인합니다. 이 문서는 정확한 마감 시각을 확정하지 않습니다.
2. **트랙:** General (Full Paper)를 선택합니다. 공식 안내는 상금 선정 대상을 이 트랙으로 한정합니다.
3. **저자 정보:** 영문 이름, 소속, 이메일, 공동저자 여부와 순서가 실제 정보와 맞는지 확인합니다. 학회는 single-blind 심사이므로 저자 표기를 유지합니다.
4. **제목·초록:** 영문 제목과 국문 초록을 사용합니다. PDF와 접수창의 제목이 같은지 확인합니다.
5. **업로드 파일:** 업로드한 PDF를 다시 열어 10쪽인지, 마지막 쪽에 Summary of This Paper가 있는지 확인합니다. 구버전 PDF를 고르지 않았는지도 확인합니다.
6. **공개 보충자료:** 논문 속 GitHub 링크를 로그아웃 상태에서도 열 수 있는지 확인합니다. 최종 원고·분석 자료·원자료는 저장소에서 연결됩니다.
7. **접수 완료:** 저장만 하고 끝내지 말고, 제출 완료 상태·논문 번호·확인 메일을 확인합니다. 저작권·중복 투고 관련 확인란은 실제 상황에 맞게 작성합니다.

공식 안내 확인일: 2026-10-25. 영문 논문, 영문 제목·국문 접수 초록, 저자 표기, 본문 2~8쪽(참고문헌·요약 제외), 요약 1쪽 조건을 확인했습니다.

## 이 버전에서 확인한 것

도입부에서 생성된 규칙이 무엇을 하는지 먼저 설명했습니다. 긴 문장을 나누고, 주어가 불분명한 표현과 반복되는 판단 문장을 정리했습니다. A2의 이득·손실과 조건부 판단, A1의 비교 범위에 따른 판단 변화가 이어지도록 다듬었습니다. 영문 초록은 기존 160단어이며 접수용 국문 초록도 그대로입니다.

수치·표·수식·그림·참고문헌과 연구의 한계를 유지했습니다. 분석 자료와 이전 공개 버전 520개 파일의 해시가 수정 전과 같습니다. 본문 8쪽, 참고문헌 1쪽, 요약 1쪽이며 학회 기본 글꼴·여백을 바꾸지 않았습니다. 새 모델 호출, 보조 에이전트, 새 시뮬레이션이나 실험은 실행하지 않았습니다.
