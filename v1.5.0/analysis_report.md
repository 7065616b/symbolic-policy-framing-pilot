# 저장된 대안 분석

A1·A2의 원래 정책을 고정하고, 각자의 도메인에 있는 원래 선택 정책 30개와 비교했다. 원래 90개 선택 정책 전체의 순위와 Pareto 상태도 기록했다. 새 모델 호출, 평가, 시뮬레이션, 난수 및 유의성 검정은 없다.

선택 효용과 저장된 테스트 효용의 순위는 별도로 계산했다. 테스트 결과로 새 정책을 선택하지 않았다. 블록 간 600개 공통 시드 비교는 이미 저장된 결과의 기술적 비교이며 생성 처리 효과가 아니다.

## A1의 선택 효용 지배 대안

A1(9노드)은 같은 Network의 7노드 원래 정책 두 개에 선택 및 테스트 Pareto 기준에서 지배된다. 두 정책의 정확한 수식은 `queue+drift-0.5*idle`이며, 대표 비교는 테스트 결과를 보지 않고 지배자 ID의 사전식 첫 항목 `pilot-Network-05-N_ROLE-slot6`로 고정했다. 선택 효용 차이는 +4.38345613e-08, 테스트 효용 차이는 +1.20835717e-05로 매우 작다.

대표 정책 대비 A1의 시드별 원점수 차이는 평균 -0.000011758, 승/무/패 9/569/22, 최악 30개 평균 -0.000306099, 최대 손실 0.001275579다. 동률은 1e-12 이내이며 작은 수치 차이에서 실질적 우열을 주장하지 않는다.

`all_alternative_comparisons.csv`는 사례당 원래 정책 30개(자기 자신 포함)와 기준식 1개, 총 62개 비교의 600시드 결합 결과를 제공한다. 승·무·패에는 1e-12 허용오차를 쓰고, 이득·손실 분해에는 부호 그대로를 쓴다. 최악 30개 평균은 관측 하위 5% 평균이며 추정 위험지표가 아니다.
